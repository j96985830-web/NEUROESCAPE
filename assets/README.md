# Atlas 3D local

El archivo oficial exacto `3d-vh-m-allen-brain.glb`, descargado de la ficha NIH 3D 3DPX-020960 (archivo 742148), está integrado en esta carpeta. La aplicación lo carga mediante la ruta relativa `assets/3d-vh-m-allen-brain.glb`.

No cambie este archivo por otro modelo anatómico: el mapeo de nodos de `data/atlas-mapping.js` fue auditado contra la jerarquía de este atlas. Mantenga la atribución y licencia CC BY 4.0 de NIH 3D en Fuentes/Créditos.
